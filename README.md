# 📊 Customer Churn Analysis Dashboard

## 📌 Overview

This project analyses customer behaviour data to identify key drivers of customer churn. The aim is to understand why customers leave and identify high-risk customer segments using an interactive dashboard built in Tableau.

---

## 🛠 Tools Used

* Tableau Public
* Microsoft Excel / CSV dataset

---

## 📁 Dataset Description

The dataset includes customer-level information such as:

* Demographics (gender, senior citizen, dependents)
* Account information (tenure, contract type)
* Services used (internet, security, support, streaming)
* Billing information (monthly charges, total charges)
* Target variable: churn status (Yes/No)

---

## 📊 Key KPIs

* Total Customers
* Churn Rate
* Average Monthly Charges
* Average Tenure

---

## 🔍 Key Insights

* Month-to-month contract customers have the highest churn rate
* New customers (low tenure) are significantly more likely to churn
* Customers with fewer additional services (e.g. tech support, security) are more likely to leave
* Payment method and contract type strongly influence customer retention

---

## 📌 Dashboard Features

* KPI summary dashboard (customer metrics and churn rate)
* Churn analysis by contract type
* Customer retention analysis by tenure
* Churn breakdown by payment method and service usage
* Interactive filters for deeper exploration
